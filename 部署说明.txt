【本地启动方式】

方法一：双击 bat 文件（推荐）
  1. 双击 "启动网页版游戏.bat"
  2. 自动启动本地服务器并打开浏览器

方法二：手动启动
  1. 进入游戏目录: d:\Users\32568\Desktop\MTC\AI自由\beatemup-game\
  2. 打开终端，运行: python -m http.server 8080
  3. 浏览器访问: http://localhost:8080/index.html

方法三：直接打开（部分功能可能受限）
  1. 双击 index.html
  2. 浏览器会直接打开（但音频等功能可能需要服务器环境）

【浏览器访问地址】
  http://localhost:8080/index.html

【如何部署到静态网站】

本游戏是纯前端项目，无需后端，可直接部署到任何静态网站托管平台。

部署步骤：
  1. 收集所有 .html, .css, .js 文件
  2. 收集 assets/ 目录下的所有素材
  3. 确保文件路径正确（相对路径，不使用绝对路径）
  4. 上传到托管平台

【推荐部署平台】
  - GitHub Pages（免费）
  - Vercel（免费）
  - Netlify（免费）
  - Cloudflare Pages（免费）

【需要上传的文件】
  核心文件:
    index.html
    style.css
    *.js（所有 JS 文件）
  素材目录:
    assets/（所有图片、音效等）

【不要上传的文件】
  - 临时文件（.bat 文件不需要上传，仅供本地使用）
  - .txt 说明文件（可选上传）
  - Godot 项目文件
  - 开发过程中的临时备份文件

【部署检查清单】
  □ index.html 作为入口页面
  □ 所有 JS 文件路径正确
  □ 所有 CSS 文件路径正确
  □ 图片资源路径正确
  □ 不依赖本地绝对路径
  □ 不依赖 Godot 或任何后端服务
  □ 在本地服务器环境下能正常游玩
  □ 在主流浏览器（Chrome/Firefox/Edge）中可正常运行

【注意事项】
  1. 确保 MIME 类型正确（.js 和 .css 文件）
  2. 如果使用 GitHub Pages，需要在仓库设置中开启 Pages
  3. 部署后测试所有功能：菜单、角色选择、三关、Boss、暂停等
